Installation & Setup

Get started building professional component workbenches using Nexus Shell. Follow these steps to install and integrate the library.

npm install nexus-shell

Basic Setup

Import the stylesheet and call the bootstrapper `initializeShell()` in your entry file (e.g. `main.tsx` or `App.tsx`): 

// App.tsx
import React from 'react';
import { ShellLayout, initializeShell } from 'nexus-shell';
import 'nexus-shell/style.css'; // Core layout tokens

// Boot registries and load stored layout state
initializeShell();

export default function App() {
  return (
    <ShellLayout
      title={<span className="font-bold">My IDE</span>}
    />
  );
}
⚠️

React 19 Requirement

Nexus Shell is built specifically for React 19. Ensure your project dependencies are updated before installing.
